# Game backup

Put the Roblox place file here: in Studio use File > Save to File As and name it `Place1_<date>.rbxl`.

- Place: Place1, id 103847533321973. The live copy is in Roblox's cloud (Creator Hub > Place1 > Version History).
- Restore: open the `.rbxl` in Studio, then File > Publish to Roblox As (a new place) or Save to Roblox.
- This repo is public. A `.rbxl` in it can be downloaded by anyone, including your game scripts. Make the repo private first if that matters to you.
